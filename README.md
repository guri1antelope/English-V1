# 目指せ英検準2級

レトロドット絵の可愛い相棒モンスターと一緒に、英検準2級合格＆DUO 3.0の例文マスターを目指す英語学習ゲームです。

## 📱 アプリの特徴

1. **英検準2級 厳選220問（全問解説・要点あんちょこ・ネイティブ音声付き）**
   - 4択空所補充問題 ＆ 語順並び替え問題
   - 全問に「日本語訳」「要点あんちょこ（文法まとめ）」「ワンポイント解説」を完全収録
   - ネイティブ英語発音（Gemini TTS）によるリスニング確認

2. **DUO 3.0 全560例文 特訓ダンジョン**
   - 現代英語の重要単語・熟語が凝縮されたDUO 3.0の全45セクション（560例文）を網羅
   - 1問ごとに100EXP獲得、自由挑戦可能

3. **相棒モンスター育成システム**
   - 柴犬、子猫、ウサギ、シマリス、ペンギンから好きな相棒を選択
   - クイズ正解やご褒美アイテム（リンゴ・お肉・金のリンゴ）でEXPを獲得
   - レベルアップとともに「タマゴ ➔ 幼体 ➔ 成体 ➔ 究極体」へと劇的進化！

4. **今日の挑戦状（デイリーチャレンジ）**
   - 1日1回限定、DUOからランダムに3問出題
   - 獲得EXPが3倍 ＆ クリア報酬として特大育成アイテム「金のリンゴ（+300EXP）」をGET！

5. **充実のデータ管理**
   - 最大4人分のセーブスロット対応（名前変更・個別初期化可能）
   - 16桁の引き継ぎコードによるセーブデータのバックアップ・復元対応

## 💻 ローカルでの動かし方（PC向け）

### 1. Pyxel がインストールされている場合
```bash
# pyxapp を直接起動
pyxel run docs/app.pyxapp
```

### 2. Python ソースコードから起動する場合
```bash
# 依存ライブラリのインストール
pip install pyxel pygame

# ゲームの起動
python3 src/main.py
```

## 📁 フォルダ構成

```
.
├── docs/                     # GitHub Pages 公開用（Web版 index.html ＆ app.pyxapp 配信用）
├── src/                      # ゲーム本体のソースコード
│   ├── main.py               # アプリケーション起点
│   ├── text_engine.py        # 日本語フォント・禁則処理描画エンジン
│   ├── graphics.py           # ドット絵グラフィック描画
│   ├── audio_engine.py       # BGM・SE・英語音声再生エンジン
│   ├── storage.py            # マルチスロット・セーブ管理
│   └── scenes/               # 各画面シーン（タイトル、ホーム、マップ、クイズ等）
├── data/                     # クイズデータ（quiz_data.json, duo_data.json）
├── assets/fonts/             # 画面描画用ビットマップフォント
├── .gitignore                # 内部開発素材（原本写真・生成ツール等）の除外設定
└── README.md
```
